# Deployment Checklist

1. Run `npm install`.
2. Run `npm run build`.
3. Run `npm run dev` and check desktop, tablet, and mobile.
4. Test these URLs:
   - `/`
   - `/crm-setup-management/`
   - `/crm-automation/`
   - `/web-app-integrations/`
   - `/business-process-automation/`
   - `/pricing/`
5. Test the contact form and confirm the message arrives through Resend.
6. Push to the same GitHub repository and wait for Vercel to deploy.
7. Submit the updated sitemap in GSC and request indexing for the four service pages.
8. Rerun the SE Ranking website audit after deployment.
