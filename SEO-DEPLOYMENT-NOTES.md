# DEG SEO deployment notes

- Run `npm install`, `npm run build`, and test all URLs locally.
- Deploy to the existing GitHub repository and Vercel project.
- Submit `https://www.digitalenterprisegroup.com/sitemap.xml` in Google Search Console.
- Request indexing for the homepage and the four canonical service pages.
- Re-run SE Ranking after Vercel finishes deploying.
- A 90–100 audit score and Top 10 rankings cannot be guaranteed; ranking also depends on competition, backlinks, authority, indexing, and time.
