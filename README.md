# Digital Enterprise Group — SEO Service Pages v17

This version keeps the existing DEG homepage, Resend contact endpoint, GA4 tag, pricing QR route, Vercel settings, and SEO foundations.

## v17 updates

- Fixed the brief unstyled/static text flash during refresh and page navigation.
- Removed the unused Tailwind/Vite dependency and kept the project on custom CSS.
- Added smooth page-exit transitions without an intro loader.
- Refined all service pages with the existing DEG visual language.
- Added an interactive system blueprint with pointer tilt and responsive motion.
- Added a moving workflow/use-case strip.
- Rebuilt the process section as an interactive step experience.
- Preserved unique SEO metadata, schema, FAQs, internal links, and sitemap entries.

## Local check

```bash
npm install
npm run dev
```

Open the local URL and test the homepage plus all five service routes.

## Production check

```bash
npm run lint
npm run build
```

Push the project contents to the same GitHub repository connected to the existing Vercel project.
